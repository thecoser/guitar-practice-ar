# Guitar Practice AR

*Your practice, within reach.*

Guitar Practice AR keeps chord shapes, lyrics, and timing cues beside the instrument while you play. Open `Guitar Practice MVP.esproj` in Lens Studio 5.25 and run SPECS Interactive Preview. Evening Room is the scene shown in the demo. A physical SPECS device is unnecessary for desktop Preview.

Start with **Home on the Range**. Use **Place chart** to position the chart, choose **Done**, and select **Play**. The [Technical readiness note](TECHNICAL-READINESS.md) includes the steps for chord loops and importing **Morning Light**.
